# 港企投资智能评测平台

HTML + CSS + 原生 JavaScript + ECharts + Node.js 的完整可运行大赛原型。模型采用固定公式和本地参数，不调用外部大模型。联网模块每日读取官方资讯元信息，与评测模块严格解耦。

## 启动

需要 **Node.js 22 或更新版本**。进入本目录执行：

```sh
npm ci
npm start
```

打开 <http://127.0.0.1:3000>，先在页面注册一个本机模拟账号，再进入应用。没有预设账号、默认口令或隐藏登录入口。请不要直接双击 `public/index.html`，测算及 PDF 需要 Node.js 接口。

第一次 `npm ci` 需要联网下载依赖及 Puppeteer 的 Chrome Headless Shell。ECharts、字体和 PDF 渲染在后续运行时都使用本地资源。Linux 需安装 Chromium 所需的系统动态库；如果使用现有 Chromium，可设置 `CHROME_PATH`。

环境参数通过进程环境变量设置，`.env.example` 是说明文件，不会自动加载：

```sh
PORT=3000 HOST=127.0.0.1 NEWS_ENABLED=1 npm start
```

Windows PowerShell 可分别设置 `$env:PORT="3000"` 等，再执行 `npm start`。默认仅监听本机。需要局域网展示时自行改用 `HOST=0.0.0.0`，浏览器密码散列功能要求 HTTPS 或 localhost 安全上下文。

## 已实现

- 模拟登录／注册、错误就近提示、加盐 SHA-256 密码散列、刷新保持与退出登录。
- 浅色／深色切换、localStorage 记忆、320px 起的移动端适配。
- 官方资讯每日一次抓取、robots 校验、请求延时、来源状态、分类／关键词检索、时间排序和未读弹窗。
- 本地政策文库：财税、公司法、跨境资金、科创、人才、园区官方指引归档。
- 五字段表单、前后端校验，两个 Worker 线程并行计算盈利与风险，一次性返回完整结果。
- 双币种税费情景、三年利润、三级评级、四维加权风险与整改、政策备选、园区推荐、分期投资。
- 技术／商务／合规岗位推演、人才支持预算敏感性、签证自查、模拟青年能力标签匹配。
- What-if 投资、园区、延迟时间与海外目标区域调整，最多 3 个新增情景与基准同时对比。
- 借港出海反向推演：四个区域的模拟营收增量、拓展费用与方向排序，独立于基础盈利。
- 当前浏览器账号的项目档案、行业相关资讯订阅、30 天计划复核及人工截止日提醒机制。
- 津港模拟企业对标，缺失指标留空，模拟数据醒目标注。
- 智能落地任务时间线、官方办理入口、完成状态、CSV 导出。
- 本地检索与模板政策问答，引用依据，资料不足时说明限制。
- 完整决策、精简摘要、合规专项三版在线预览与真实 PDF 下载，含中文字体和 SVG 图表。
- 咨询记录仅存浏览器，不调用接口、不发送邮件；展示 `.example` 保留域名演示邮箱。

## 必须理解的口径

**本项目是职业规划大赛原型，不是投资、税务、法律或移民服务。**

1. 除明确引用的香港官方税率及 ESS 条件，其余行业、成本、增长、汇率、风险、岗位及出海系数均是【项目演示假设】。人民币输入，演示汇率 `1 CNY = 1.08 HKD`，并非实时汇率。
2. 五字段不足以判断资格。基础情景按公司标准利得税率 16.5%，两级制单列为待核验备选；不自动认定离岸免税。确认资助为 0；潜在资助与人才支持预算不混入基础利润、不互相叠加。
3. 内地采用京津冀一般工商业简化演示：净 VAT、附加、企业所得税。不覆盖地方临时优惠、混合销售、出口退税、特殊纳税人及全部跨境税务安排。综合税款差额不是可直接实现的节税额。
4. 默认 `lastHumanVerifiedAt` 为 `null`，页面与报告显示“尚未人工核验”。开发过程核对公开网页，不代表专业人士已人工审定。
5. 企业档案、咨询、模拟账号和任务均只保存在浏览器。清除站点数据会丢失记录；换端或换浏览器不会同步，请导出 PDF。前端账号没有生产级身份验证和权限控制。
6. 模拟案例和人才不是实际企业／个人。现有公开资料不足以提供真实津冀企业利润、获批资助或盈利周期，平台不会补造。
7. 目标海外区域与延迟时间仅在情景面板填写。延迟冻结模型政策快照，仅调整演示成本与风险；出海增量单列，不伪装成确定利润。

## 官方资讯与参数隔离

```text
官方公开 RSS / 列表 → robots + 延时 → storage/news-cache.json → 资讯、站内提醒

人工核验 → 手动编辑 data/*.json → 重启 Node → 盈利 / 风险 Worker → 评测与报告
```

抓取器只保存标题、发布日期、短摘要和原文链接，以及来源、分类和缓存时间等必要元数据。不抓正文；不执行官方页面脚本；不接受用户输入的抓取网址。RSS 优先使用香港政府新闻公报 `general_en.xml`。投资推广署与政府新闻网配置了轻量列表适配器，robots 不可可靠读取或页面结构不匹配时保守跳过，页面明确显示原因，保留历史缓存。

后端启动时检查持久化的频率门槛；到期才抓取，此后每 24 小时检查一次。失败也要等待下一轮。每站请求至少间隔 2.5 秒，遵循更长的 robots crawl-delay；无法遵循的来源跳过。跨进程锁避免手动命令与服务同时抓取。单进程持续运行才能执行定时任务；停机时不抓取，重启按门槛补检查。

```sh
npm run news:sync
```

手动命令同样受每日一次限制，不提供浏览器“强制刷新源站”接口。首次联网失败时资讯显示空状态；不使用伪新闻填充。资讯缓存可按需保留或删除，部署包不包含缓存，首次启动自动抓取。

站内每分钟读取本机缓存，**不会每分钟访问官方源**。订阅不发邮件／短信，不在浏览器关闭后推送。公告相关性用固定关键词初筛，不声称已判断法律效力或模型影响。

## 手动更新模型

1. 查阅官方原文，记录适用日期、条件与限制；由人工核验人员审定。
2. 修改 `data/rules.json` 或相关行业、园区、政策文件。不要编辑新闻缓存来更新税制。
3. 提升 `rules.version`，填写实际完成的 `lastHumanVerifiedAt`，并更新资料核对记录。
4. 执行测试，重启服务。配置在启动时读取，资讯任务不能热改模型。
5. 新模型用于新评测，浏览器历史报告保留原始结果。若导出时发现模型哈希改变，接口返回 409，要求重新评测，避免静默替换历史数值。需要长期导出历史快照时应提前保存原 PDF。

政策文库条目支持人工填写 `deadline`（ISO 日期）；只有人工核验、适用于该行业的日期才产生到期提醒。默认没有已核验的固定截止日，平台不会虚构补贴窗口或法定期限。30 天复核提醒是项目管理建议，不是法律规定。

## 验证

```sh
npm test
npm run test:browser
```

后端测试覆盖税率临界点、非法字段、可复现性、亏损、资助隔离、行业规模组合、延迟情景、资讯解析及接口。真实浏览器验收覆盖账号隔离、刷新、图表、三个版本 PDF、沙盘、检索、问答、咨询零 POST 请求、主题与 320/390px 页面溢出检查。

受限自动化环境若不允许 Chromium 创建多进程，可**仅在测试时**使用：

```sh
BROWSER_TEST_SINGLE_PROCESS=1 npm run test:browser
```

该测试选项会关闭浏览器自身沙箱并改为单进程，正常运行不要启用。默认 PDF 浏览器保留自身沙箱。测试生成的截图与三版示例 PDF 位于 `examples/`；报告样例全部是演示输入，不是真实企业材料。

## 文件入口

- `public/index.html`、`public/css/app.css`：应用结构、商务主题及响应式样式。
- `public/js/app.js`、`views.js`：交互与全部业务视图。
- `public/js/auth.js`、`storage.js`：模拟账号和用户本地数据。
- `public/js/charts.js`：独立 ECharts 配置，前端与 PDF 共用。
- `server/assessment.js`、`model-worker.js`、`models/`：双模型与联动逻辑。
- `server/news.js`、`data/news-sources.json`：资讯更新，和模型解耦。
- `server/report.js`、`public/js/report-template.js`：报告与 PDF。
- `data/`：官方条目索引、演示规则、模拟案例及标签。
- `docs/`：架构、逐项公式、来源及验收说明。
- `assets/fonts/`：本地中文字体及 SIL OFL 许可证。

无在线大模型密钥、无真实身份信息、无后台账号数据库。依赖以 `package-lock.json` 锁定；部署应使用 `npm ci`。
